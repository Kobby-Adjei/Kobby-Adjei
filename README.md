## Kobby Adjei

CS @ Eastern Michigan University · building AI products and doing interpretability research.

I learn by building. Most of what's here is real work in progress — three things I care about most:

**[Project K](https://github.com/Kobby-Adjei/project-k)** — failure attribution for video AI. I test where multimodal models lose sound, with the same clips and the same questions put to every model, sound on, muted, and blacked out. Four open models have run the full battery so far, and each one loses the sound in a different place. The method, the data notes, and every result are public in the repo.

**[GuruEd](https://gurued.dev)** — live coding education platform. Zoom-style sessions, Scrimba-style recordings (Syncs), and an AI tutor that sees your screen in real time.

**[Dumb Ways to Die](https://github.com/Kobby-Adjei/dumbwaystodie)** — use the chat you already pay for as your coding agent. When your agent runs out of tokens, the ChatGPT or Claude tab already open answers instead, with your code attached (VS Code extension, local relay, browser add-on, no API keys).

**[STONNE tools](https://github.com/ssamaha3-hub/stonne-tools)** — experiment automation for STONNE, a neural network accelerator simulator (team project). I built the sweep config parser and validation for all STONNE operations, the sweep expander and command builder, and the energy and results aggregation across runs.
